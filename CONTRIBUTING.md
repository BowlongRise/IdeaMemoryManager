# Contributing to IdeaMemoryManager

Thank you for your interest in contributing to **IdeaMemoryManager**!

Developed and maintained by **BowlongRise**, this project welcomes contributions from developers worldwide.

## Code Standards
- Keep Core logic decoupled from Windows Forms UI.
- Use ICleanStrategy when proposing additional optimization strategies.
- Write clear, concise code comments in English.
- Do not commit machine-specific paths or confidential developer environment details.

## Submitting Pull Requests
1. Fork the repository.
2. Create a dedicated feature branch (git checkout -b feature/your-feature).
3. Verify that dotnet build -c Release compiles cleanly with zero warnings.
4. Open a pull request with a descriptive summary of your changes.
